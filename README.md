
# SupeRR Selector – Rajasthan Royals Analytics Challenge

## Project Overview

A cricket analytics project focused on identifying reliable
batters and bowlers under pressure using ball-by-ball data.

## Objectives

- Identify the top 10 reliable batters under pressure.
- Identify the top 10 reliable bowlers under pressure.
- Analyse player performance using statistical methods.
- Develop a pressure-based player scoring model.

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- uv
- Git and GitHub

## Project Structure

- data/: Competition datasets
- notebooks/: Exploratory analysis
- src/: Python analysis scripts
- reports/: Analysis reports and visualizations
- outputs/: Final player rankings

## Workflow

1. Exploratory Data Analysis
2. Data Cleaning
3. Pressure Situation Identification
4. Statistical Modelling
5. Player Ranking
6. Methodology Report
